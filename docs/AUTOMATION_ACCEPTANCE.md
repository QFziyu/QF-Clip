## 使用与剩余限制

1. 双击 `launch.cmd --profile gpu`；切换 CPU 前运行 `stop_automation.cmd` 再开 `launch.cmd --profile cpu`。CPU 项目、缓存和调度记录独立，固定端口同一时刻只运行一套自动配置。
2. Edge 轻舟扩展重新加载为 **1.2.0**，点“连接自动工作流”；第一步贴回放地址并选模板。默认比赛模板至少 90 分钟；短样片用不限时长的自定义模板或对话模板。
3. 候选就绪进入工作台，第三、四步保存人工修改，第五步“完成本批审核并自动导出”。仅通过项输出，旧成品保留。

关网页后后台继续；关机后重新启动同一入口恢复。停止流程不会强杀已确认的导出；它仍可完成并在第五步显示。MP4未知时长、多个回放、登录/签名/身份问题需协助，不能猜测下载对象。单固定偏移对轴、双路自动来源、多平台适配、开播录制与边录边剪不属于本次自动生产首期；原有手动双路仍可使用。

本报告交付的是已运行的程序与证据，真实平台整场全链路验证仍需用户可播放的 Edge 会话与实际素材。素材授权范围沿用用户提供的权利边界，不推定赛事画面可跨平台发布。

公开源码中的回放地址为占位示例。实际样本由操作者通过 `scripts/verify_real_download.py --url "实际回放地址"` 传入，个人回放链接不写入源码。
