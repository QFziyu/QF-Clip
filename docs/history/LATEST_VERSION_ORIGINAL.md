# 当前版本：1.8.6

主目录：`D:\Codex\FootballClipFactory`。

双击 `launch.cmd`，在同一个菜单选择 CPU／GPU、本地制作／制作与发布。两种设备均运行当前源码，CPU 不再从 `v1.7.1-cpu` 启动旧代码。旧启动入口已移到工作区备份。

剪辑形式统一为“切片”“全场集锦”“连续长段”。所有剪辑形式共用一行必剪事件输入与模型双模式配置。

完整操作说明见 [统一启动与模型双模式](../UNIFIED_START.md)。

新增独立本地中文 ASR：设置 → 本地语音识别，可在 Zipformer 中文 CPU 与原有 Whisper 间切换。
选片、标题、可选字幕校对仍属于独立 LLM 步骤，不会因更换 ASR 自动变成本地大模型。
部署与实际验证见 [本地中文 ASR 接入报告](../LOCAL_ASR_ACCEPTANCE.md)。
