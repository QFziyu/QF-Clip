## 1. 结论

**工程功能验收通过，可开始使用最终版测试自己的录像。真实赛事选片效果和整场生产性能尚未验收。**

已交付可运行的 Python 程序、配置、Streamlit 审批页、SQLite 持久化、后台队列、测试脚本、依赖锁定文件、启动器及 Agent Skill。输入、转录、选片、预览、审批、成品导出已连通；自动化测试 **99 项全部通过，0 失败、0 错误、0 跳过**。

额外实际运行了 75 秒中文合成视频：真实 tiny Whisper CPU 推理 → 本地 OpenAI 风格 HTTP 夹具 → 3 条预览 → 3 条测试审批 → 仅导出通过的 2 条 × 横竖屏 = **4 个全高清 MP4**。四个成品均完整解码通过，字幕、时长和原片时间映射检查通过。重复运行未重新加载 ASR 模型、未重复请求选片接口、未重新编码相同成品。

本报告没有把模拟 LLM 当作真实模型，也没有把程序登记的测试审批当作真人审核。没有使用用户的真实比赛录像、没有付费 API 调用。候选质量、足球术语准确率、每小时候选数量和真实语境下的标题事实，仍需真实素材确认。

## 2. 用户先测试这个版本

双击 [launch.cmd](../../launch.cmd)，或在 PowerShell 执行：

```powershell
cd D:\Codex\FootballClipFactory
.\launch.cmd
```

审批页默认地址：[http://127.0.0.1:8501/](http://127.0.0.1:8501/)。当前电脑的 Python 依赖和 FFmpeg 路径已经配置。可先打开现有“模拟”演示项目，测试播放、修改标题、审批保存和导出；演示素材是测试图，不能据此评价真实足球内容质量。

然后仅在**最终版**完成一次真实素材验收：

1. 在 `.env` 填写 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL`。密钥不进入源码或版本包。
2. 选择自己的 5～10 分钟录像；多音轨先用 `python main.py probe "录像路径"` 确认解说轨道。
3. 在网页“项目”导入录像，选择“语义 + 声音辅助”。本机 CUDA 运行库尚缺失，请勾选“CUDA 不可用时允许 CPU 回退”，或设置 `DEVICE=cpu`、`COMPUTE_TYPE=int8`。默认 medium 首次使用仍需下载模型；CPU 处理速度会较慢。
4. 在“任务队列”查看转录和渲染日志。关闭网页不会中断后台任务。
5. 在“审批工作台”至少检查 3 条：试听音轨，核对原文、字幕同步、起止范围和标题事实，分别通过或拒绝，尝试修改标题/字幕，刷新后确认保存。
6. 导出已通过切片，可同时选择横屏和竖屏；检查 MP4、SRT/ASS、发布文案与时间映射。只以当前 `export_manifest.json` 为有效成品清单。
7. 这段素材通过后，再扩大到 60 分钟及整场录像。

没有 API 时可选择“仅声音辅助”，它不会下载 Whisper 或调用 LLM；没有已有转录时不会生成自动语音字幕。它适合测试能量突变候选，不替代完整语义选片验收。

## 5. 版本保留与回退

**只需先测试最终版。** 若最终版无法使用，优先试候选版，再试基线版，不需要把历史源码覆盖回主目录。

| 版本 | 用途 | 从主目录启动 | 数据位置 |

| v1.0-final | 默认最终交付，完整功能与最终文档 | `.\launch.cmd` | 主项目 `cache/`、`output/` |
| v0.9-rc | 功能与 99 项测试通过时的候选检查点；最终报告和启动显示细节封存前 | `.\launch.cmd --version v0.9-rc` | `FootballClipFactory_Releases/release-data/v0.9-rc/` |
| v0.1-baseline | 本轮加固前的最小端到端、审批和导出基线；保留原 59 项测试版本 | `.\launch.cmd --version v0.1-baseline` | `FootballClipFactory_Releases/release-data/v0.1-baseline/` |

两个历史版本默认分别在 8503、8502 端口运行。它们的数据目录独立、初始为空，需重新导入同一原片进行测试，不会自动降级或覆盖主数据库。每个版本另有 SQLite 在线备份保存在 `data-snapshots/版本名/`，保留已提交的 WAL 数据；不自动覆盖正在使用的审批记录。

快照包含源码 ZIP 和 SHA256 清单，不含 `.env`、原片、模型、缓存、依赖环境或生成视频。默认复用当前主项目 Python 环境；如果怀疑依赖问题，可执行 `powershell -ExecutionPolicy Bypass -File scripts/setup.ps1 -Version v0.9-rc` 为该版本创建专用环境。当前依赖锁定 53 个项目依赖，未打包所有离线安装轮子。

正常启动会核对源码；最终版允许用户修改 settings、选片规则、术语和 Prompt 四个明确配置文件。严格版本校验仍会报告这些自定义差异。已有快照禁止覆盖，主项目原片及密钥不会被版本工具删除。

## 6. 未验收与暂未实现

- **本机环境限制：** 尚未配置 API 密钥与模型名称；Whisper CUDA 实际加载缺少 `cublas64_12.dll`。可先用 CPU，之后补齐与 CTranslate2 匹配的 CUDA/cuDNN 运行库。NVENC 成功不等于 CUDA 转录已可用。
- **真实数据待验收：** 5～10 分钟真实直播、60～180 分钟吞吐/稳定性、medium 模型准确率、实际服务商兼容性、每小时 15～30 条候选的有效召回率。不会为了数量填造时间戳。
- **有意保持 MVP 的部分：** 声音分析只检测能量变化；没有笑声/情绪专门分类、画面进球识别、自动运镜、目录监听、直播平台接入、可编辑 Premiere/After Effects 时间线、人工切片对照评估或训练/微调。
- **事实核验仍需人工：** 时间戳与原文引用能约束素材来源，不能自动证明标题、说明或解说的全部事实。术语词典用于识别提示和人工修订参考，不做未经校验的全局替换。
- **发布与授权：** 不含自动投稿。使用非原创素材时，需分别确认主播内容、赛事画面、音乐及目标平台的授权范围；主播切片许可不自动涵盖赛事转播画面的跨平台使用权。
