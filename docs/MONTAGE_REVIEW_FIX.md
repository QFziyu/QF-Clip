# 1.6.2 整批长集锦与审核预览修复验收

日期：2026-10-24。

## 问题与修复

旧版将“数量 2 条”分别应用到每个输入文件，当前 8 份素材中有内容的文件合计生成了 10 条候选。工作台预览还把每个组成区间限制在前 20 秒，导致审核视频和实际成品范围不一致。

新版增加“多素材制作范围”：

- **整批合成**：素材按所选顺序组成虚拟时间轴，数量和时长仅在整批应用一次。多素材集锦默认此方式。
- **分别制作**：每份素材各自产生指定数量，保留原有批处理用途。
- 第二步明确显示“整批总计”或“每份素材”，可查看和修改顺序。AI 集锦无需先编码整场拼接视频，只渲染实际选中的范围。
- 审核列表显示最终成品数量和每条时长；组成片段另列在折叠面板，数量多于 4 条时使用紧凑下拉选择。
- 工作台预览保留全部区间和完整时长，只降低分辨率和码率。旧版截短预览不会被当作当前全长预览。
- 审批、标题、字幕、横竖屏和唯一正式导出入口保持兼容。任务日志、范围编辑、重复警告默认折叠。
- 双路对轴步骤的“20 秒同步预览”仍是专门的同步检查工具，与第三步完整成品预览用途不同。
- 按用户后续要求，默认字幕字号从 48 改为 34（约 71%）；横屏底部间距从 60 调至 36、竖屏从 150 调至 105，字幕向下移动。当前项目同步保存此样式并重新生成全长预览，字幕文字和时间不变。预览现在使用项目已保存的包装设置，样式变化会让旧预览失效。

## 使用

1. 启动最新 GPU 入口 `launch.cmd --profile gpu`（CPU 入口 `launch.cmd --profile cpu`）。
2. 当前项目直接进入第三步，可切换两条完整视频、修改标题并保存审批。
3. 新项目导入多份素材后，第二步选择“多段集锦”和“整批合成”，设置整批数量 1 或 2、每条目标时长。
4. 第四步核对字幕和包装，第五步统一导出通过项。
