# Football Clip Factory 1.3.0 双路合成验收

验收日期：2026-10-18。范围：比赛录像与主播录像合成；保留已有剪辑、人工字幕和审批数据。

## 已完成

- 独立网页「双路合成」工作区及 SQLite 项目、设置审计、同步结果和输出历史。
- 主画面完整等比缩放；主播默认完整画面、宽度 25%、左下角。宽度 10%～50%、四角位置、音量和声音来源可选。
- 可选 16:9 人脸裁剪：OpenCV 自带 Haar 检测器、抽样检测和平滑位置，失检回退，FFmpeg 动态 crop 指令；本机已安装 OpenCV。
- 全片声音指纹匹配，不限制为开头相近；三处分散局部细匹配、多个候选与可信度。手动偏移、同一事件两路时间校准、任意位置 20 秒预览、确认后整段导出。
- 可选 Whisper + LLM 语义事件辅助，限量摘录、合法 ID 校验、多个一致事件锚点、预算账本与缓存。ASR/API 失败保留声音结果和已完成缓存。默认声音匹配不调用 API。
- 后台队列、关闭网页后继续、选定范围导出；CLI 额外支持最多 200 个区间拼接。NVENC 编码失败回退软件，原始 PTS 对齐，文件名用自定义标题，继承目录访问权限。
- MP4、时间轴映射和设置元数据；输出可重新导入原有 AI 切片流程。不同设置生成新输出，保留历史视频。

操作步骤和 CLI 示例见 [DUAL_COMPOSITION.md](DUAL_COMPOSITION.md)。

## 明确的验证边界

- 尚未收到用户这次要合成的真实两路录像，**没有完成真实赛事双路对轴试验**。
- 人脸坐标逻辑、动态裁剪命令及真实解码已测试；**未完成真人素材的追踪质量评估**。多人、侧脸、遮挡会降低可靠性，默认完整缩放仍可用。
- 语义辅助使用模拟 API/转录验证，没有为本次升级调用真实付费 API或下载模型；不能承诺不同解说精确自动同步。
- 三小时规模测试为特征矩阵，不是三小时双路视频渲染压力测试。
- 使用固定偏移，不自动纠正中途插播、剪断或时钟漂移。应分段校准。
- 网页通过 Streamlit AppTest 验证交互；本次未完成真实浏览器逐项视觉验收。
- 当前合成输出为横屏，原有切片模块仍可继续导出竖屏与编辑字幕。
