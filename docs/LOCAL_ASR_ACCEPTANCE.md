本次已保存 `.env.asr`，默认本地 CPU 识别、关闭 LLM 字幕校对。新版工作台本次启动地址为 `http://127.0.0.1:8502/`（旧 8501 进程未被强行停止）；项目库可选择末尾“本地中文字幕对照”的项目查看本次完整预览。

已有项目需要返回第二步重新生成方案，才能使用新引擎；已有人工字幕和历史成品保留。只做本地转录可以运行：

```powershell
.venv\Scripts\python.exe main.py process "D:/videos/录像.mp4" --transcript-only --skip-render
```

直接运行 CLI 或 Streamlit 前，若服务没启动，运行 `D:\Codex\Hugging Face\Start-ASR-Background.cmd`；健康检查 `/health`，诊断 `python main.py doctor`。选择 Whisper 即可恢复原本的 GPU/CPU 识别配置。

## 边界与诚实说明

本次已完成上述 172 分钟真实录像缓存音频的新模型转录和完整集锦渲染，但没有独立人工真值，因此没有 CER/WER 或优于 Whisper 的准确率结论。实测仍存在“中厂”“切耳机”等专名错误及 `<unk>`。该小模型不自动恢复标点，也不支持原 Whisper 的足球术语 prompt；人工字幕编辑保持可用。原 Whisper 本身也是本地语音识别，接入本模型不代表原识别必然为付费云端服务。

CTC 提供词元起点，字尾为参考下一字起点并限制延展的估计；不是强制对齐。含复杂中英混说或极端噪声的输出若无法与原生解码核对，会停止该块并保留已完成块，不伪造时间戳。

**免费本地语音识别不等于全流程不用大模型。** 选片、标题和开启后的字幕校对仍使用现有 LLM 来源及其额度/预算。本地转录样片验证无 LLM 调用。首次未隔离的旧回归测试误触发了现有 Codex 路线，已中止测试及其子进程；此后回归采用隔离入口，不应把初次旧测试表述为零模型调用。
