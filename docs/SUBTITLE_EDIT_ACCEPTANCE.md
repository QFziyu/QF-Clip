# 字幕查找替换与识别标记清理验收

日期：2026-11-04，Asia/Shanghai。版本：1.8.8。

## 功能

- 工作台第四步、旧候选审核和独立方案字幕编辑复用同一组件；第三步视频预览下增加“修改字幕”入口，直接定位到刚才预览的成品，不误选列表第一条。
- “查找与替换”按钮，快捷键 Ctrl+Shift+F；按当前视频字幕正文精确匹配，展示匹配字幕条数及出现次数，不查找 SRT 序号或时间戳。
- “全部替换”只修改匹配正文，支持替换为空。删除后成为空白的字幕行移除，其余时间轴保留。无效 SRT、空搜索、换行注入被拒绝；支持撤销上次批量操作，手动继续改字后禁用旧撤销，避免丢失新输入。
- 操作修改编辑草稿，沿用现有“保存此条人工字幕”持久化与审计、修订机制。保存后刷新可恢复；旧成品不覆盖，新预览随新字幕重新生成。
- 默认自动过滤已知 ASR 控制词/未知词标记，过滤发生在按行分割和裁切前，支持跨转录段的 `<unk>` 及开头 `unk>`；保留正文原有字级起止位置和原始缓存，不重新识别或调用 LLM。
- 旧 SRT 可批量清理跨字幕条拆开的模型标记；默认保留数字、英文和标点。额外提供显式“仅保留汉字与标点”选项，勾选后数字和英文也会删除；普通英文和比分不在默认自动清理范围内。
- 替换仅限当前成品，不自动修改其他成品或维护永久热词词典。逐条字幕内部精确匹配，不跨不同时间条拼接并改写人名。
