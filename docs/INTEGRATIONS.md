# 可选外部服务

仅使用本地文件、Whisper 和人工审核时，不需要安装下面的独立项目。本仓库包含客户端及协议边界，没有复制目录外的服务实现。

| 能力 | 独立组件 | 当前连接方式与限制 |
| --- | --- | --- |
| 来源下载 | 轻舟下载器及浏览器扩展 | 默认查找同级 `软件下载/轻舟视频下载`；服务端口 17653 |
| 自动来源调度 | `FootballWorkflow` | 默认查找同级同名目录；调度器端口 17654 |
| 工厂控制 API | 本仓库 `scripts/factory_service.py` | 自动流程端口 17655；只监听本机 |
| 浏览器发布 | `FootballPublisher` | 同级同名目录，端口 17656；另需 Edge、Playwright 与用户会话 |
| 中文 Zipformer | 原独立 ASR 服务 | 默认查找同级 `Hugging Face`；默认回环端口 8765，严格校验模型身份和时间戳能力 |

当前启动器对这些目录存在约定；`launch_automation.py` 提供 `--hub-root` 和 `--lightboat-root` 参数，完整参数见其 `--help`。没有服务时使用 `launch.cmd --profile cpu` 进行本地制作，不必创建假的外部目录。

统一启动器若探测到调度器和下载器，会尝试启动自动流程。独立服务不可用时会显示错误并尝试打开本地工作台。CPU 与 GPU 自动流程共用固定控制端口，同一时刻只启用一个自动配置；切换前使用停止自动服务入口，未知进程不会被强制关闭。

`--publishing` 只用于具备独立发布组件的部署。配对令牌保存在运行目录；复制源码不能复制登录状态或完成账号配置。真实平台提交结果不明时应先核验，不能通过重新提交来猜测结果。

`tests/test_production_automation.py` 中的工厂自身测试可独立运行；协调器测试仅在同级存在 `FootballWorkflow/flowhub/service.py` 时启用。需要完整集成验收时另行安装并测试外部组件，不能用“跳过”来代表这些功能已通过。

历史 `AUTOMATION_API.md`、`PUBLISHING_GUIDE.md` 等文档保留了原部署的协议和操作细节，其中绝对路径只是原安装示例。
