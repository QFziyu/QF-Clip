# 抖音发布试点 · 使用说明（1.7.0）

## 入口

- 本地素材＋发布：双击 `D:\Codex\FootballClipFactory\launch.cmd --profile gpu --publishing`。CPU 使用 `launch.cmd --profile cpu --publishing`。
- 来源链接自动生产＋发布：使用 `launch.cmd --profile gpu` / `launch.cmd --profile cpu`。
- 只做本地剪辑：原有 `launch.cmd --profile gpu` / `launch.cmd --profile cpu` 继续可用；也可以在设置中点击“启动发布服务”。
- GPU/CPU 后台接口使用同一组端口，切换前运行 `stop_automation.cmd`。数据环境各自独立，不能同时启动两套后台服务。

本机已安装 Playwright 和 Edge。新机器执行 `.venv\Scripts\python.exe -m pip install -r requirements-publish.txt`，安装官方 Microsoft Edge。无需下载另一个 Chromium。

## 首次连接与试点

1. 打开工作台“设置”，点击“连接抖音账号（打开 Edge）”。这是独立发布窗口，不复用日常 Edge 的 Cookie。自行完成正常登录、扫码和验证码。
2. 点击“刷新账号身份”，核对页面识别的抖音号，点击“确认此账号”。若无法唯一识别账号，系统会暂停；不要只根据昵称猜测身份。
3. 按原来五步制作、审核视频，保存人工标题、发布说明和字幕。第五步选择“导出并发布到抖音”，只选一种发布画幅。
4. 首次选择“准备发布”，核对本批冻结内容并勾选授权，点击“导出并准备发布到抖音”。后台先完成正式渲染和校验，再打开网页上传填写。
5. 在 Edge 检查视频、账号和文案。此模式不会点击网页“发布”。可自行发布后在第五步填作品 ID 核验；不发布则停止任务。准备中的作品会阻止后续上传，以免覆盖当前表单。
6. 样片正确后，可在设置勾选检查样片并启用自动提交。随后批次第五步可以选择“自动提交发布”，仍需对本批内容授权。校准样片须先核验或停止，队列才能继续。

当前网页适配器尚未在你的真实抖音账号上校准。遇到账号身份、上传成功标志、编辑框或发布按钮无法识别时，会显示需要协助。自定义封面的网页控件也尚未完成真实校准，选择自定义封面会暂停等待检查；默认封面可用于首轮试点。不要将本地模拟测试理解为真实平台验证完成。

## 状态与恢复

| 状态 | 含义与操作 |
|---|---|
| 等待上传 / 正在上传 | 后台继续；关闭工作台网页不会取消任务，保持电脑与发布 Edge 运行 |
| 已上传 · 等待最终发布 | 检查当前 Edge 表单；手动发布后核验作品 ID，或停止此任务，才继续下一条 |
| 需要登录 / 账号不一致 | 在独立 Edge 恢复正确账号，刷新身份，再重试尚未提交的任务 |
| 已提交 | 网页出现提交成功，但尚无可核验的作品回执；不视为公开发布完成 |
| 发布结果待核实 | 提交后失联；先在创作者中心查结果，填入真实作品 ID 核验，禁止直接重新投稿 |
| 已发布 | 指定作品 ID 与页面标题匹配；页面提供作品链接。平台以后仍可能变更作品状态 |
| 未完成 / 需要处理 | 查看原因；尚未开始提交的任务可恢复，已开始提交的不自动重发 |

发布失败保留本地 MP4、SRT/ASS、标题说明和时间映射。恢复发布不重新转录或选片。标题、字幕、封面、范围或账号修改后需重新检查并确认；历史作品不会自动补发。

服务重启：重新运行原入口。端口占用报错时先运行 `stop_automation.cmd`；启动器仅停止归属已核实的服务，不关闭未知进程。Windows 重启后需要重新启动入口，不安装开机常驻任务。

## 文件与边界

- 发布代码：`D:\Codex\FootballPublisher`；运行库、上传副本和独立 Edge 会话：其 `runtime\gpu` / `runtime\cpu`。源码包不含这些数据和本机令牌。
- 工厂日志：当前数据环境 `output\.automation\publisher.log`、`factory.log`。
- 原有来源自动化的真实平台边界保持：海星短样片已有测试；咪咕依赖登录会话，完整真实链路仍待实测。
- 此版本不提供官方无人值守投稿 API，不处理验证码，不自动撤回远端作品，不包含多账号、定时发布或直播录制。

抖音官方 H5/SDK 能力与本地网页适配器不同，不能用旧接口教程替代实际应用权限。官方说明见 [发布能力使用规范](https://developer.open-douyin.com/docs/resource/zh-CN/dop/operation-standard/platform-capabilities/useclue)。
