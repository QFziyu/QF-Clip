这条流程是 **本地 CPU 音频识别 → API 文字语义复核 → 自动预览**。API 本次没有接收音频，不属于两套独立 ASR 交叉识别，也不保证所有专名准确。

## 使用说明与边界

打开第三步直接播放和审核这 30 条；保存审核后到第五步，勾选所需通过项，再点“开始导出”。本次已恢复自动初始预览，“重新生成预览”仅用于后续修改或故障重试。

程序仍不提供独立云端音频 ASR 对照。原转录中的含糊人名可能需要人工替换；低分不会自动拒绝。全局导出不自动重发已发布作品。

AI 控制现已具备能力、环境摘要、项目清单、导出预检/提交与任务恢复；旧计划中的精确文件级缓存预演、百分比/心跳规范化和跨平台实时发布回执汇总尚未完整实现，不能把本报告当作这些高级能力的验收。
