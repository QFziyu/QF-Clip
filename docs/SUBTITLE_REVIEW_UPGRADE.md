# 自动字幕 AI 校对 · 1.6.3 验收报告

验收日期：2026-10-24～25（北京时间）。本次只增加字幕自动校对，第二项改进已由用户取消。

## 已实现

- 自动字幕生成后调用用户配置的 OpenAI 兼容模型，校对明显错字、同音误识别、足球专名和明显不通顺表达，保留口语及原意。
- 按最多 48 条 / 3200 字分批，附前后只读上下文，使用结构化 JSON；兼容现有网关格式降级、超时重试和项目 API 预算。
- 字幕 ID、数量、起止时间不交给模型修改。数字变化、空字幕、控制字符、重复或越界 ID、大幅改写会被拦截。不能靠文字校对证明比赛事实；不确定的专名仍需人工检查。
- 原始转录及其快照保留。校对缓存保存原文、模型建议、应用结果和失败状态，预览与横竖屏导出共用缓存，不重复转录。
- 人工保存或导入的字幕跳过自动校对。时间范围更改继续保留人工字幕，并沿用原有“需要核对”的保护。
- 网络失败或预算不足保留原文；显式重试只补失败批次，成功批次复用。网页读取状态不发 API 请求。
- 已接入普通候选、连续长片、多段集锦、双路工作台、旧版方案和 CLI 渲染入口。正式输出保留原文 SRT / ASS 及校对报告用于追溯；已有历史成品不覆盖。

## 使用方法

1. 新项目默认开启：生成候选后自动校对，之后正常审核、修改和导出。
2. 已有项目进入第四步“字幕与包装”，勾选“自动字幕生成后使用 AI 校对”。
3. 展开“AI 校对记录与重试”，点击“AI 校对本批自动字幕（失败项可重试）”。后台完成后点击“载入最新进度”，查看修正数量及原文对照。
4. 需要调整时直接编辑 SRT 并“保存此条人工字幕”；之后自动校对会跳过此条。已有未保存文字时，先保存再启动批次校对。
5. 第三步生成新预览或第五步导出会复用缓存。关闭校对：取消复选框后保存包装；全局设置在 `config/settings.yaml` 的 `subtitle_review`。

没有配置 API 时不会伪造校对成功；缓存已经存在则可离线读取。选片与校对共用同一项目账本，达到预算或调用上限时不会重置预算。
