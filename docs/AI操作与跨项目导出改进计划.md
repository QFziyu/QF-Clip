# AI 操作与跨项目导出改进计划

状态：全局导出、共享业务接口和字幕评分修复已实施（v1.9.0）。实际验收与剩余边界见 docs/ACCEPTANCE_1.9.0.md；原计划中的高级预演与监控字段不能据此视为全部完成。

## 现状

主链路已经可用，具备缓存、持久化队列、预览、人工审批和导出。对 AI 的操作接口尚不完整，实际接手还需要拼接界面、数据库、日志信息。

代码确认：ui/workbench.py 的 export_step 只读取当前项目的 active_variant；core/workflow.py 的 export_snapshot 也只冻结当前方案的 approved 项，因此最后一步无法显示其他项目已通过的内容。这是当前产品范围限制，不是用户操作错误。

## 1. 将第五步改为全局导出中心（优先）

- 默认范围为当前数据环境的全部项目，不再受左侧当前项目限制。
- 跨项目汇总所有仍有效、已通过的成品；包含已通过的非当前方案，明确标注方案名。已归档或被替代的旧修订单列历史，避免当作新内容。
- 表格展示：勾选、人工标题、项目/方案、时长、字幕状态、最近修改、导出状态、发布状态。
- 默认勾选尚未导出或内容已修改的通过项；已导出的当前版本仍显示，默认不重复勾选；支持主动重新导出。
- 待审核、拒绝项不进入待导出清单。全部项目没有通过项才显示空状态。
- 保留当前项目筛选，并提供全部项目、日期、导出状态筛选、全选、取消全选和返回对应审核项。
- GPU/CPU 独立数据环境明确标识；首期不混读两套数据库。需要合并时另做显式数据导入。

## 2. 跨项目批量任务和可靠恢复

- 建立一个父批次，按项目拆成子任务，沿用现有 workflow_export 和单重任务队列。
- 只导出用户实际勾选的项。提交时冻结其修订、人工标题/字幕、素材范围、包装和编码参数。
- 每项独立预检查：素材缺失、字幕待核对、无效范围等逐项显示；问题项取消勾选后其他项仍可导出，不以一个错误拦住整个清单。
- 默认沿用每个项目的字幕/片头；画幅、分辨率、编码、目标目录统一设置。覆盖全部项目的包装须显式选择。
- 幂等键绑定成品修订与渲染设置；双击、请求超时和重启不重复渲染。失败只重试失败项。
- 目录按批次/项目组织，文件名采用人工标题；同名加短 ID。保留旧成品，不覆盖历史文件。
- 导出中上游发生修改时，本批次依照冻结快照完成并标注历史；不会悄悄换用新内容。
- 本地导出与平台发布分开记录。已发布的内容不会因为重新导出被再次发布；发布仍需明确选择并确认本批内容。

## 3. 给 AI 一个统一控制入口

- 在现有本机控制服务及 CLI 上扩充同一业务接口，不让 Agent 直接读写内部表。
- 提供能力查询、环境身份、项目/方案/成品查询、批次计划、提交、状态、取消和失败项恢复。
- 增加只读预检/预演：返回将处理哪些条目、是否命中缓存、预计产生哪些文件和阻塞问题，再提交执行。
- 所有动作返回稳定 ID、修订号和结构化错误码；错误附带可执行恢复建议与是否可重试。
- 状态统一为排队、运行、等待人工、成功、部分成功、失败、取消；返回阶段、进度、最后心跳和结果路径。
- 人工审批与发布授权保持独立，AI 自动处理不能自行把候选标记为已通过。

## 4. 降低任务接手成本

- 提供全局状态摘要：运行任务、待审核数量、待导出数量、失败原因、建议下一步。
- 一份任务清单串联源文件、转录/校对缓存、候选、人工修订、预览、成品及发布记录。
- UI 与 AI 共用服务层，确保点击按钮与调用命令行为一致。
- 更新项目 SKILL，给出查询、提交、等待、恢复和验收命令；禁止把临时脚本当正常操作接口。
- 日志统一关联批次和子任务 ID，默认不输出 API Key 或登录凭据。

## 实施顺序

1. 全局已通过清单与筛选，保持现有项目/审批数据 ID。
2. 逐项快照、跨项目父批次、断点恢复和历史管理。
3. 完善统一 API/CLI、预演与结构化状态，更新 Agent 使用文档。
4. UI 和真实 FFmpeg 样片回归，交付验收报告。

## 验收

- 三个项目分别通过 2、1、1 条，第五步默认显示全部 4 条；切换左侧项目不丢失全局清单。
- 非当前有效方案的已通过项可见，归档/被替代修订单独标明；待审核、拒绝项不会误导出。
- 勾选部分条目仅输出所选内容；中文同名标题不冲突；人工字幕、片头及横竖屏正确。
- 已导出项保留显示，未修改的重复点击可复用；修改后显示需要更新并保留旧成品。
- 一个素材缺失不影响其他有效项；中断重启恢复；失败仅重试失败条目。
- AI 通过公开接口完成查询、预演、提交、进度及结果验证，无需手写 SQL 或临时脚本。
- 回归单路、拼接、集锦、双路，核对旧审批和手工字幕不变；正式发布不因导出重试而重复。
