| 原功能与数据 | 单素材入口、声音/语义对轴、画中画、审批、字幕及导出继续可用；不改写原视频或已有成品 |

5. 真实 FFmpeg 测试验证无音轨素材接入后仍可正常生成画面，补齐部分为静音；验证缓存复用及中途失败后的恢复。

## 验证边界及暂未实现

- 看图 API 的图片消息格式、结构验证、已知帧关联、缓存和错误恢复通过模拟接口验证；**没有运行真实视觉模型识别真实比赛进球的验收**，不宣称其识别成功率。
- 此版由用户圈定同一事件的大概范围，每路不超过 600 秒、8～32 帧；没有实现自动扫描整场录像寻找全部进球、完整比赛时钟 OCR、跨录制缺口的多段偏移或漂移自动修复。
- 主播录像需要包含比赛画面，只有人脸时无法视觉对应现场事件。回放、不同镜头、重复开球均可能误配；画面匹配始终为低置信度建议，不能跳过预览确认。
- 拼接是直接首尾连接，不补漏录时长、不自动消除两段之间重录的内容。出现缺段时需分项目校准。工作副本会额外占用磁盘。
- 本次主要验证新拼接及同步功能；GPU/CPU 保留同一源码的两种运行配置，本次未重新下载 ASR、人脸或去人声模型验证真人效果。
