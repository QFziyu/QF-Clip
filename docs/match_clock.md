# 一行事件与自动比赛对轴

在工作台第二步选择「多段拼接集锦」，展开「内容标准、数量、时长与必剪事件」中的「比赛分钟校准与必剪事件」。
只需在「必剪事件（一行填写）」输入：

```text
G23:10 R40 / G61 V90+3:20
```

- `G` 进球，`R` 红牌，`V` VAR；不区分大小写，也支持 `23:10G`。
- 空格分隔事件，`/` 分隔上下半场。下半场使用累计分钟，如 `61`，不是 `16`。
- 上半场补时写 `G45+2:10`，下半场补时写 `V90+3:20`。
- 仅有下半场事件时写 `/ G61`。第三、第四段可填写加时上下半场，例如 `/ / G100 / R119`。
- 其他事件用 `E35[任意说明]`；不需要逐行填写事件表。

「自动识别记分牌并对轴」默认开启。设置事件前后保留秒数后，直接生成方案即可，无需填写录像位置。
程序用 Python/FFmpeg 抽取画面，调用「大模型设置」中的 API 模型读取左上角或右上角记分牌。
API 模型必须支持图片输入；即使文字选片使用 Codex CLI，记分牌识别仍使用保存的 API 配置。

程序先在录像各处抽帧发现半场偏移，再在每个事件附近核对两张画面的时间是否正常前进。
计时采用累计分钟；主钟 `47:10` 与 `45+2:10` 均可识别，主钟停在 `45:00` 且另有 `02:10` 补时计时器时也可识别。
裁判宣布的 `+4` 等补时时长不会加到主钟上，避免重复计算。半场休息、停表、回放、低置信度读数不会直接生成校准点。

图片和 API 结果按原片签名缓存；识别与选片共用项目 API 次数/费用预算，失败后已完成部分可复用。
识别不清楚、源片缺少该事件或录制发生删节时，会保留明确的未定位提示，未确认事件仍会阻止导出。
自动定位不代替原有事件预览确认。自动校准结果在审核页可展开查看。

若需修正特殊素材，可关闭自动识别后使用原有高级校准表。
旧配置未指定 `clock_mode` 时仍按原有手动逻辑运行；新配置可设置 `"clock_mode": "auto"`。

单独读取一张记分牌图片（使用项目 API 配置）：

```powershell
.\.venv\Scripts\python.exe scripts\read_match_clock.py "D:\素材\记分牌.png"
```

在录像中自动定位事件：

```powershell
.\.venv\Scripts\python.exe scripts\read_match_clock.py "D:\素材\比赛.mkv" --events "G23:10 / R61 V90+3:20"
```
